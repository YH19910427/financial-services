# シグナル台帳 v1 — 提案の根拠を拾う

> 位置づけ：**提案サポートの下請け**。カルテの数字をここに当て、引っかかった項目を「切り口カタログ」に渡す。シグナルは材料であって結論ではない。
> 目安の数字は全部仮置き。試験会社で当てたら「調整ログ」に書く。

## 判定の出し方
1. カルテの数字をこの表に当て、S 番号ごとに「強／中／弱／該当なし／未取得」を付ける
2. 「未取得」はそのまま提案メモの §7 に流す（見本で埋めない）
3. 強が 1 つでもあれば、その切り口を提案メモの比較表に必ず載せる
4. **PBR が高い会社（S1〜S4 が空振り）は、S5／S6／S15 と S10 の節目で切り口を出す**

## 調整ログ
- 2026-11-01 試験 3 社（スタンレー電気・J.フロント・ZOZO）で判定。気づき：
  - **S8**：5% 未満でも有報の大株主上位 10 にアクティビスト名が出る（スタンレー：シティインデックスイレブンス 3.1%）。get_major_shareholders を必ず見る
  - **S4**：持ち合い（スタンレー⇄ホンダ）は一方向の表では見えない。保有先とこちらの大株主を突合する
  - **S12**：edinetdb の賃貸等不動産注記は J.フロントで 2017 年までしか無い。簿価 6,377 億円のように大きい場合は原本を読む
  - **screen_companies**：ネットキャッシュ比率などの比率は小数で指定（30% → 0.3）。% で指定すると 0 件になる
  - **型ごとの当たり方**：割安・現金リッチ型は S1/S3/S4 が強く出て A1/A2。アクティビスト型は S8 の「保有目的」文がそのまま提案の骨子になる。親子上場型は S7 だけが強く、A5 一択に近い
- 2026-10-31 ソニー（6758）で初回判定。気づき：
  - **S2 の落とし穴**：有報 XBRL の純利益は非継続事業込み（ソニーは金融分離で −3,269 億円）。ROE を「継続事業ベース」で計算し直す手順を S2 に追加する。edinetdb の ROE 欄をそのまま使うと誤判定
  - **S10 の拡張**：「未達」だけでなく「次の中計の策定時期」を節目シグナルとして持つ（提案のタイミング）
  - **S12 の拡張**：不動産だけでなく「分離後に残した上場関連会社の持分」（SFGI 16.4%）を非事業資産として扱う
  - **高評価企業への当て方**：PBR が高い会社は S1〜S4 がほぼ空振りになる。そのときは S5／S6／S15（ポートフォリオ・再編）と中計の節目で切り口を出す
