## 0. 立場を変えると何が変わるか（テストの設計）

**今期に決めること（優先順）**：①第六次中計の財務フレーム ②I&SS の資本の外部化ロードマップ ③最適資本構成（ネットキャッシュ目標・自己株 2.4 億株の消却・負債活用の上限）。
**今期に説明すること**：投資家の関心（CG 報告書の列挙）＝ポートフォリオと M&A の考え方、IP シナジー、生成 AI の機会とリスク、還元方針。これに「数字で答える棚」を作る。

## 3. 課題ツリー（何が問題か、数字で）

```
企業価値を次の 3 年でどう上げるか
├─ I1 分離後の「目指す BS」が空白 ──────── 自己資本比率 23%→52%、ネットキャッシュ 1.33 兆。目標なし
├─ I2 I&SS の投資効率 ──────────────── 営業利益率 17.4% だが減価償却 2,651 億、TSMC JV で資本の持ち方が動く
├─ I3 FCF の薄さと還元の整合 ─────────── FCF −249 億 vs 還元 6,486 億（要確認：投資 CF の中身）
├─ I4 低収益セグメントの資本効率 ─────── ET&S 7.3%（−17%）、映画 7.1%（−11%）。セグメント ROIC 未開示
├─ I5 非事業資産 ─────────────────── SFGI 16.4%（簿価・時価 未取得）、政策保有 1,290 億（提携株）

├─ I7 開示の「数字の空白」 ───────────── ROIC・資本コストを「把握」とだけ記述。投資家の関心は「ポートフォリオ・M&A の考え方」
├─ I8 インセンティブの整合 ───────────── 執行役報酬の 76% が株式系。資本効率 KPI の有無 未取得
├─ I9 格付けとレバレッジ ─────────────── ネットキャッシュだが半導体投資サイクル。格付け維持と負債活用の上限が未定義
└─ I10 財務直結リスク ───────────────── 地震（センサー工場の国内集中）、FX、メモリ価格高騰（CEO 発言）、年金、繰延税金
```

### 各課題の読み（一言ずつ）
- **I1 が根**。BS の目標が無いと、I2（JV にどこまで資本を出すか）も I3（還元をいくらにするか）も I6（M&A にいくら使うか）も決められない。銀行員メモでは第 2 提案だったが、社内では**最初に決めるべき枠**。
- **I2** は「分離すべきか」ではなく「資本をどこまで自社で持つか」の問題として置き直す。JV（ソニー過半）・外部パートナー・ファンド・将来上場は、同じ軸上の目盛り。
- **I3** は数字の確認が先。投資 CF 1.97 兆に金融事業の分離（現金の連結除外）が含まれるなら、事業ベースの FCF はもっと大きい。**確認せずに「FCF がマイナス」と外に言うのは危険**。
- **I4** は「切り出し」ではなく「セグメント別 ROIC を社内で揃え、資本コストを下回る事業に撤退基準を置く」ことが先。TV の TCL 合弁はその実例。
- **I7** は I1〜I4 を**数字で外に出すかどうか**の意思決定。東証のポイント（目指す BS、キャッシュアロケーション方針、セグメント別の資本コストと収益性）と一致する。
- **I8** は外からは見えにくいが、社内 AI なら必ず当てる。株価連動が強いのは良いが、**資本効率 KPI（ROIC スプレッド）が無いと「株価のために還元を増やす」誘因**が残る。

## 5. 取締役会への論点メモ（CFO 室が用意する形）

1. **決めてほしいこと**：第六次中計の財務フレームとして、目指す BS（自己資本比率・ネットキャッシュ）のレンジと、セグメント別ハードルレートを採用するか
2. **選択肢**：(a) 現状維持（定性記述のまま） (b) 社内では数値管理、開示は定性 (c) 社内・開示とも数値
3. **判断材料**：東証ポイントの要請、投資家の関心事項、アクティビスト先例、同業の開示水準（未取得：日立・パナソニック HD・任天堂の開示比較）
4. **リスク**：数値を出すと未達が目立つ／出さないと「把握していない」と見られる。SFGI 分離で BS が変わった今は、**基準年を置き直す好機**
5. **次回までに**：事業ベース FCF の確定、資本コストの社内算定、I&SS の 3 シナリオ
